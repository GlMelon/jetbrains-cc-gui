根因回顾

现状抽屉 session-capabilities.less 中 .session-capabilities-drawer 为右侧固定面板， width: min(360px, calc(100vw - 16px))，且 @media (max-width: 600px) 时退化为 width: 100% —— 工具窗口常态宽度低于 600px，因此几乎总是呈现「全屏」观感。以下三个方案均将内容 DOM 保持不变、仅替换容器形态。

实现要点：① 所有动效均为纯 CSS animation / CSS 变量驱动，无需新增依赖；② FadeContent 是「装饰子元素不加 wrapper」的设计，直接套在现有 <CapabilityItem> 上即可，不破坏 flex 布局；③ CountUp 自带 rAF 饥饿兜底（JCEF webview 后台挂载场景不会冻在 0）；④ 打开弹窗时按 index 重设 --rb-fade-delay 即可重放入场动画；⑤ 全部动效已含 prefers-reduced-motion 降级。

维度A · 居中模态 推荐B · PopoverC · 内联面板

推荐结论：主线落 方案 A（居中模态）；若后续需要「边聊边瞄一眼能力」的低打扰入口，可将方案 B 作为二级快捷视图叠加，两者共用同一内容组件。
