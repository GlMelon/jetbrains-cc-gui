关于"双层"根因（独立于视觉重做）：调研确认 What's New 的双层隐患来自两个独立 ChangelogDialog 实例—— AppDialogs.tsx:156（初始化自动弹，写 localStorage）与 settings/CommunitySection/index.tsx:71（手动点开，独立 state，不写 localStorage）。 git 历史里没有专门修复此双层的提交；最相关的是 5ccbe05c（统一 BaseDialog，消除旧"双 overlay"）与 4be5937e（JCEF 残影）。 修复建议（与视觉重做解耦）：删除 CommunitySection 的第二实例，设置页改为调用全局 openChangelogDialog()（复用 UIStateContext 单一 state），统一 onClose 行为（都写 localStorage）。这样无论选上面哪套视觉方案，双层都不再出现。
