📋 方案对比

方案 推理图标风格 模式图标风格 优点 缺点
方案一 仪表盘（参考 Claude gauge） Claude 官方图标 与 Claude 官方一致，用户熟悉 仪表盘图标较复杂，小尺寸可能不清晰
方案二 圆点进度（参考 Codex） 简洁 toggle 风格 简洁直观，易于识别强度 与项目现有风格差异较大
方案三 脑+线条混合 混合风格 结合官方和项目现有风格 需要更多设计调整
🎯 推荐方案：
• 推理程度：方案二（圆点进度风格）- 最简洁直观，用户可快速识别强度
• 模式图标：方案一（Claude 官方风格）- 与官方保持一致，降低学习成本
• 新增 ultra：建议添加，与 OpenAI GPT-5.6 对齐，仅在 provider 支持时显示
⚠️ 实施建议：
1. 推理图标建议使用圆点进度风格（方案二），因为：
- 最简洁，小尺寸下清晰可辨
- 与 OpenAI Codex 的 "juice" 概念一致
- 用户可直观理解强度（1-5个点）
2. 模式图标建议使用 Claude 官方风格（方案一），因为：
- brain/gauge/compass/bolt 是官方定义的图标
- 降低用户学习成本
- 与 Claude 官网和文档保持一致
