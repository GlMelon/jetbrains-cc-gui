推荐 · MVP

会话能力摘要卡

在每轮 assistant 首次输出前插入可折叠卡片。信息密度适中，历史消息可回看，最符合“当前会话”语义。

轻量

聊天头部状态胶囊

固定在 Chat header 显示“4 MCP · 2 Skill”。占用空间小，但不易关联具体 turn，也不适合记录历史。

完整

右侧能力抽屉

展示完整工具、来源、权限与加载时间。可扩展性最好，但占用空间更大，移动宽度下需要折叠。
