📋 改动说明

  • 根因① 高度不一：5 个控件共享 .selector-button（padding:5px 10px），但「设置/供应商」是纯图标、其余带文字，无显式高度导致纯图标按钮矮 2~3px。

  • 修复：给 .selector-button 加 height:28px; box-sizing:border-box；给 .button-area-left 加 gap（方案A=8px / 方案B=6px+竖线）。
