优化说明 根因

核心问题
  • 市场弹窗专属类(mcp-market-dialog / market-key-section / market-search / market-source-tabs / market-scope-select / market-error / market-empty / market-toast)在 LESS 中完全未定义,只复用了 preset-item 卡片,导致 Key 区、搜索框、Tab、scope 全靠裸 div 堆叠 → 排版简陋。本次补齐全部专属样式。
MCP 市场
  • API Key 横幅:用左边框色区分状态(未配置=警示黄 / 已配置=成功绿),masked key 用 mono 字体高亮,操作按钮内联,视觉层次清晰。
  • 搜索框:带前缀搜索图标 + focus 蓝色光晕,搜索按钮并排。
  • 结果统计行:新增"共 N 个结果 / 来源",信息密度提升。
  • 卡片 meta:REMOTE/LOCAL 改为彩色圆点 pill(绿=远程/蓝=本地),已验证用对勾徽章,安装数弱化,层级分明。
  • 添加按钮:hover 时整卡上浮 + 添加钮变蓝高亮,交互反馈明确。
Skills 市场
  • 源仓库 Tab:底部下划线指示器(蓝色),含仓库路径弱化展示,切换语义清晰。
  • scope 选择:从松散按钮改为分段控件(segmented control),选中态蓝色填充,更紧凑现代。
  • 卡片:路径用 mono 字体 pill,补充分类标签,安装按钮常驻主色。
  • 状态块统一:空态/错误/toast 三态补充图标与配色,告别纯文字。
通用
  • 统一圆角(8/6px)、间距系统(8/12/14/20)、阴影;卡片 hover 微上浮;滚动条美化。
  • 沿用项目设计 token(--accent #007fd4、8 色哈希图标),与既有 preset 卡片视觉一致,可平滑落地。
