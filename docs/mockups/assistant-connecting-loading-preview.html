落地建议

  • 默认使用推荐方案 B：呼吸点 + dots + 光扫，信息量够但不吵。
  • 超过约 3 秒时展示 indeterminate progress 和三阶段 stepper，降低“卡住”的感觉。
  • 文案保持两层：主标题 Connecting，副标题 Starting the selected AI runtime Claude。
  • 背景继续使用 v0.4.5 的 `--color-message-card-bg` 色系，避免现在偏蓝。
  • 动画只使用 transform / opacity / background-position，避免频繁布局重排。
