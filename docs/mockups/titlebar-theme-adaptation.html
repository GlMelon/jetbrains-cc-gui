💡 设计思路：
标题栏背景色使用新的 CSS 变量 --bg-titlebar，默认值跟随 --bg-secondary（或 --bg-tertiary）， 与 header 和聊天区域自然过渡。

核心改动：
• 暗色主题: #252526 (与 header 一致)，不再使用 #000
• 亮色主题: #e8e8e8 (与 tertiary 融合)
• Darcula: #3c3f41 (JetBrains 风格)
• 自定义背景: 跟随用户的 --bg-secondary 值

实现方式：在 variables.less 中新增 --bg-titlebar 变量，标题栏组件引用该变量即可。 用户自定义聊天背景时，标题栏自动跟随，无需额外处理。
