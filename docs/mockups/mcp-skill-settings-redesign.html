优化说明 vs 现状

现状痛点
  • MCP 卡片信息扁:只有"图标+名称+状态点",描述 / 命令 / 工具数都要展开才看到,卡片大面积留白;状态仅一个小图标不醒目;hover 只变边框。
  • Skills 卡片辨识低:描述同样藏在展开里;所有 Skill 都是同一个 folder 图标,一眼分不清;路径作为纯文本,层级弱。
  • Skills 工具栏拥挤:全部 / 全局 / 本项目 / 分隔符 / 已启用 / 已停用 6 个 tab 挤一行,主分类与启用筛选用同一种控件,语义混在一起。
  • 两处都缺少全局统计(共多少、几个在线/错误/停用),用户无法一眼掌握整体状态。
MCP 服务器面板
  • 统计条:header 下方新增"已连接 / 错误 / 已停用 / 共 N"彩色圆点条,整体状态一目了然。
  • 卡片信息前置:描述摘要(1 行省略)、工具数 pill、LOCAL/REMOTE、命令 mono pill 全部常驻卡片,无需展开即可判断。
  • 状态 pill 体系:已连接=绿、错误=红、停用=灰,带圆点,比单纯图标醒目且配色统一。
  • 操作收纳:编辑/复制/删除默认半透明,hover 整卡上浮时才完全显现,降低视觉噪声;右侧 iOS toggle 保留总开关。
  • 展开区结构化:版本/命令/主页用键值网格 + 代码底纹;工具改为 chip 流式布局(含"+N more");tags、操作分区清晰。
Skills 面板
  • 筛选分层:主分类(全部/全局/本项目)用分段控件;启用状态(已启用/已停用)改为独立的胶囊筛选 pill,语义分离、不再 6 tab 挤一行。
  • 彩色辨识图标:每个 Skill 用语义 emoji + 哈希色块(替代统一 folder),一眼可辨。
  • 摘要常驻:描述 1 行省略 + 路径 mono pill 常驻;版本号弱化 pill;展开后才显示完整描述与编辑/删除。
  • 启用态视觉:左侧按钮式 toggle,启用=绿色填充对勾、停用=灰色禁止,与卡片整体禁用降透明联动。
通用
  • 沿用市场弹窗设计 token(#007fd4 / #4ec9b0、8 色哈希图标、pill、分段控件、hover 上浮),两个设置面板与市场弹窗视觉语言统一。
  • 圆角(8/6)、间距系统(8/10/12/14)、阴影、滚动条统一;卡片组件类与既有 .preset-item 风格一致,可平滑落地到 LESS。
  • 市场入口独立按钮:「🛒 从市场获取」从原添加/导入下拉中拎出,做成独立主色按钮(带 NEW 角标),与「＋ 手动配置 / 导入本地」次要幽灵按钮并列、置于最右。市场是发现型新功能需推广,主入口不该藏在二级菜单;手动/导入属低频兜底,弱化为配角。MCP 与 Skills 两边对称。
