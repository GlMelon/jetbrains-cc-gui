这版按方案 A 保留原工具区交互，同时解决宽度跳动：

  • assistant 外层列使用统一宽度，例如 min(820px, calc(100vw - 150px))。
  • 每张 assistant 卡片都 width: 100%，不由内容决定宽度。
  • 短回复不会收缩；长路径、长命令、diff、JSON 只在内部省略、换行或滚动。

宽度策略

  • assistant 消息卡片不再使用内容自适应宽度。
  • 同一聊天区域内，assistant 卡片左右边界稳定。
  • 短内容保持固定宽度，避免卡片忽小。
  • 长内容在内部处理，避免卡片忽大。
  • 用户气泡仍可保持按内容宽度，只有 assistant 卡片固定。
