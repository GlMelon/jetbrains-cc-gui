修复 3: 亮色主题适配 (StatusPanel.less)

[data-theme="light"] .status-panel-tabs {
  background: rgba(0, 0, 0, 0.04);
  border: 1px solid rgba(0, 0, 0, 0.08);
}

[data-theme="light"] .status-panel-tab:not(:last-child)::after {
  background: rgba(0, 0, 0, 0.1);
}

[data-theme="light"] .status-panel-tab.active {
  background: rgba(0, 0, 0, 0.06);
}
⚠ 根因分析：--bg-chat-overlay-light 和 --bg-chat-border 两个 CSS 变量在项目中从未被定义。 它们仅在 StatusPanel.less 中被引用，但 variables.less 中没有声明，也没有通过 JS 动态注入。 这导致 var() 回退为空值（transparent），使得标签栏背景完全透明，与 #2b2d30 底色融为一体。

修复策略：不新增变量，直接使用 rgba() 半透明色值，既能适配暗色/亮色主题，又不增加变量维护负担。
