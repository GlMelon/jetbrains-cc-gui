落地清单 · 真实代码修复点(供开发者对照)

1
给 .dialog-base 补容器样式(根因修复 · 解决“背景透明”) —— webview/src/styles/less/components/agent-dialog.less 新增(ConfirmDialog/所有 BaseDialog 共用): /* .dialog-base 此前无任何定义 → 弹窗透明 */ .dialog-base { background: var(--bg-secondary); border: 1px solid var(--border-secondary); border-radius: 10px; box-shadow: var(--shadow-lg); overflow: hidden; display: flex; flex-direction: column; max-width: 90%; }
2
标题颜色统一到主题标题色(解决“标题灰”) —— .dialog-header h3: color: var(--vscode-foreground, var(--text-primary)); /* 深色下 #ccc 偏灰 */ color: var(--text-secondary); /* 深色 #e0e0e0 / 浅色 #1a1a1a,更亮的标题色 */ 注:mcp.less:729 与 skills.less:191 两处同款写法,建议一并收敛。
3
遮罩升级为方案一毛玻璃 —— ConfirmDialog 实际走的是 .dialog-overlay(非 .confirm-dialog-overlay,后者是 legacy 死代码)。当前 .dialog-overlay 有两处冲突定义: agent-dialog.less:14 → blur(4px) z-index:1100 mcp.less:666 → blur(8px) z-index:1000 /* 最终生效,但被前者污染 */ /* 合并去重,统一为方案一 */ .dialog-overlay { background: var(--overlay-mask-bg, rgba(0,0,0,0.4)); backdrop-filter: blur(12px) saturate(125%); -webkit-backdrop-filter: blur(12px) saturate(125%); z-index: var(--z-modal-backdrop, 1040); }
4
遮罩色抽成主题变量(深浅适配)—— variables.less: /* dark */ --overlay-mask-bg: rgba(0,0,0,0.40); /* light */ --overlay-mask-bg: rgba(40,44,52,0.18); --overlay-blur: 12px; 这样浅色主题下遮罩不会发黑(用半透明深灰而非纯黑)。

说明:以上为纯 HTML/CSS 效果图,直接双击在浏览器打开即可。backdrop-filter 模糊需 Chromium 内核(JCEF / Edge / Chrome)支持,JCEF 默认满足。
第 1 条是关键:只要给 .dialog-base 补上不透明背景,“背景透明”与连带产生的“弹窗看起来脏/灰”会一并消失;再配合第 2~4 条即为本图效果。
