供应商弹窗重设计 · 双层问题排查与优化方案

问题:所有用 BaseDialog 的供应商弹窗(Provider/Codex/OpenCode),在 de7177f7 给 .dialog-base 补齐卡片样式后, 内层遗留的 .dialog 与外层 .dialog-base 两层卡片背景/边框/阴影叠加,视觉上"框里套框"。 下面是 4 个基于现有表单布局的优化方向预览。

根因诊断 BUG

真·双层 DOM(仅 3 个供应商弹窗中招): ProviderDialog.tsx:556 / CodexProviderDialog.tsx:192 / OpenCodeProviderDialog.tsx:133 在 <BaseDialog> 内部又套了 <div class="dialog provider-dialog">。 .dialog-base(bg+border+r12+shadow) 与 .dialog(bg+border+r8+shadow) 各自一套完整卡片样式叠加。

引入点:de7177f7 "Refine dialog and chat input styling"(2026-06-18)。此前 .dialog-base 无任何定义(透明),内层 .dialog 是唯一可见卡片=单层;该提交给 .dialog-base 补齐卡片样式后=双层。同时把遮罩 blur 从 4px→12px+saturate,毛玻璃本身也变厚重。

What's New(ChangelogDialog):代码上是单层(.changelog-dialog 无 bg/border/shadow),它显厚重是受同一个毛玻璃遮罩影响,非真双层。如下方案对"所有弹窗"统一有效。

❌ 现状(三层嵌套 · 双层卡片)
.dialog-overlay — 毛玻璃遮罩 blur12
└ .dialog-base ← 卡片① bg+border+r12+shadow
└ .dialog.provider-dialog ← 卡片② bg+border+r8+shadow
├ .dialog-header
├ .dialog-body
└ .dialog-footer
✅ 修复后(两层 · 单层卡片)
.dialog-overlay — 柔和遮罩 blur6
└ .dialog-base ← 唯一卡片 bg+border+r12+shadow
├ .dialog-header
├ .dialog-body (去掉内层 .dialog)
└ .dialog-footer
